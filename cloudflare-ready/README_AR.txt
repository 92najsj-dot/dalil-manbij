خطوات التجهيز قبل رفع الموقع:
1) افتح Supabase للمشروع الصحيح: keadoflmrwqpdjauzbhc.
2) افتح SQL Editor، والصق محتوى SETUP_SUPABASE.sql وشغّله مرة واحدة. لا تشغّل أي SQL آخر غير هذا الملف لهذه الحزمة.
3) تأكد أن Storage bucket باسم manbij-images موجود، عام للقراءة، وحدّ حجم الملف 5MB وأنواع الصور JPG/PNG/WebP/AVIF. تم التحقق من وجوده بهذه الإعدادات وقت إعداد الحزمة.
4) في Cloudflare Pages ارفع **محتويات هذا المجلد** كجذر للموقع: index.html وملفا Google وملف README (لا ترفع مستودع GitHub الكامل ولا مجلد cloudflare-ready كطبقة داخلية).
5) بعد الرفع اختبر: الصفحة الرئيسية، تسجيل الدخول، إنشاء إعلان تجريبي، رفع صورة، ظهور الحالة في «إعلاناتي وطلباتي»، ورفض إعلان مع سبب، ثم الموافقة عليه. استخدم حساباً تجريبياً ولا تختبر بصلاحيات المدير إلا بحساب المدير الحقيقي.
6) افتح ملف التحقق الحالي مباشرة على النطاق الذي تريد إثباته، ثم ارجع إلى Search Console واضغط «التحقق».

مهم:
- هذه الحزمة محفوظة على فرع GitHub مستقل، ولم تُنشر تلقائياً إلى الموقع الأساسي.
- حالات المنشور/المرفوض وسبب الرفض تظهر لصاحب المحتوى في «إعلاناتي وطلباتي» عند دخوله للموقع؛ لا يوجد حالياً إرسال إشعارات خارجية بالبريد أو إشعارات الهاتف.
- الحذف الذاتي يعتمد على تشغيل ملف SQL أعلاه؛ لا تتجاوز خطوة SQL.
- لوحة الإدارة تعتمد على role=admin داخل app_metadata في جلسة Supabase.
- لا تضع مفتاح service_role في كود المتصفح. أبقِ RLS مفعّلاً.
- لم يتم إجراء اختبار متصفح كامل على أجهزة حقيقية؛ نفّذ قائمة الاختبار قبل اعتبار النسخة جاهزة للإطلاق العام.
- رفع Cloudflare Direct Upload يستبدل ملفات النشر الحالية؛ ارفع جميع الملفات اللازمة معاً.
